## javadoc (shared text rules — T04 and T05 must use these)
- `HtmlTextFormatter.format(html)` — code/tt → backticks (not inside `<pre>`/links), `<a>` → plain text (no backticks, so `{@link}` HTML matches T04's plain `Foo#bar`), `<p>`/headings → blank line, br/div/tr → newline, `<pre>` verbatim (tags dropped, entities decoded, outer blank lines and **common indentation removed**), `ul/ol` → `- item` (nested +2 spaces), `dt` line / `dd` indented line, others stripped, nbsp → space, whitespace collapsed, no trailing spaces.
- `FirstSentenceExtractor.extract(plainText)` — to first `.` + whitespace; skips e.g./i.e./vs./cf./etc-like abbreviations (not `etc.`), periods inside backticks; stops at blank line, `- ` list line or indented (pre) line; result is one line.
- `BlockTagFormatter` — `param(name,text)`, `returns`, `throwsTag(type,text)`, `since`, `deprecated`, `see`, `line(tag,text)` for others (`apiNote` etc.); collapses whitespace to one line.
- Note for T04/T05: javadoc HTML renders `{@link Foo#bar(int)}` as `Foo.bar(int)`; T04 renders `Foo#bar(int)`. Reconcile if you need identical text (e.g. T05 mapping link labels), the formatter only takes the link's text.
