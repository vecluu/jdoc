# T07 notes — text output primitives and query primitives

logging, no Lombok needed. Packages depend only on `model`.

## text
- `TextResult(header, List<TextBlock>)` — the result text model (header line + body blocks). `builder(header)`
  `.line/.blankLine/.lines/.block(List|TextBlock).build()`, `ofLines(header, lines)`, `bodyLines()`, `allLines()`,
  `text()`. Lines must not contain `\n`/`\r` (IllegalArgumentException). T10's `CommandResult` should wrap this.
- `TextBlock(lines)` — lines kept on one page where possible (e.g. one method's Javadoc); `of(...)`, `line(s)`.
- `TokenBudget(maxTokens)` — `defaultBudget()` (2,000), `maxCharacters()` (= tokens × 4), static
  `estimateTokens(text)` (chars/4 rounded up), `fits(text)`.
- `Paginator(TokenBudget)` / `Paginator()` — `paginate(result, commandLine)` → `List<Page>`;
  `page(result, n, commandLine)` → `PageOutcome`. Fits ⇒ one page, no footer. Otherwise every page = header + body
  + footer, all counted against the budget (each line counted with its `\n`). Footer room is reserved for the
  widest page number (re-split if the page count gains a digit). Blocks move whole to the next page; a block larger
  than a page is split by lines; a single line longer than a page gets its own page (the only case that can exceed
  the budget). Body lines of all pages concatenate back to the result body.
- `Page(number, total, lines)` — `text()`, `hasNext()`, `printedCharacters()`.
- `PageOutcome` (sealed) — `Shown(page)` | `OutOfRange(requested, total)` with `message()`
  (`page 5 does not exist: this result has 3 pages`); callers map OutOfRange to exit 1 ("not found").
- `PageFooter(commandLine)` — `footer(n, total)`: `page 1/3 · next: <cmd> --page 2` / last page `page 3/3`;
  static `withoutPageOption(cmd)` strips `--page N`, `--page=N` and a dangling `--page` anywhere in the line.
- `ColumnLayout(maxLeftWidth=48, gap=2)` — `format(rows[, indent])`; `ColumnLayout.Row.of(left, right)`. Left
  column padded to the widest entry that is ≤ the cap; wider entries just get the gap; empty right cell → no
  trailing spaces; widths in code points.
- `ResultHeader(TypeDescriptor, artifactLabel, versionUnresolved)` / `ResultHeader.of(type, ArtifactKey, bool)` —
  `line()`: `displayName+typeParams  modifiers kind  (label)  [doc-source tag]  [version unresolved]`, two-space
  separators, e.g. `java.util.Optional<T>  public final class  (jdk 25)`. Tag text comes from
  `DocSource.headerTag()`. No `[deprecated]` tag (not in the spec).

## query
- `ParseResult<T>` (sealed `Success(result)` | `Failure(message)`) — `value()`, `error()`, `isSuccess()`, `map`,
  `orElseThrow()`. All parsers return this; malformed input never throws.
- `TypeReferenceParser.parse(text)` → `TypeReference(input, names, candidates)`; `simpleName()`, `isSimpleName()`,
  `matches(TypeName)`. Type args in input are ignored (`Optional<T>`).
- `TypeCandidate` (sealed): `Exact(TypeName)` — exact binary name; `Relative(simpleNames)` — any package, type's
  `simpleNames()` must END with the given chain (`[Entry]` matches `java.util.Map$Entry`; T09 decides whether to
  use that leniency). Both have `simpleName()` (for the index's simple-name column) and `matches(TypeName)`.
  Order: Relative first if the first piece is upper-case or there is one piece; then the conventional split
  (package = pieces before the first upper-case piece); then other splits, top-level reading first. `$` is always
  nesting (TypeName's rule). Examples: `Optional` → [Relative(Optional)]; `java.util.Map.Entry` →
  [java.util.Map$Entry, java.util.Map.Entry, java.util$Map$Entry, java$util$Map$Entry];
  `Map.Entry` → [Relative(Map,Entry), Exact(Map.Entry)].
- `MemberReferenceParser.parse(text)` → `MemberReference(input, type, name, constructor, Optional<List<String>>
  parameterTypes)`; `allOverloads()` when no parens; `()` = empty list. `Type#Type` and `Type#<init>` →
  `constructor=true`, `name` = type's simple name (matches `MemberDescriptor` convention).
- `ParameterTypes.normalize(text)` → `ParseResult<String>`: erase generics, `...`→`[]`, whitespace removed, qualified
  / nested names reduced to the last simple name (`java.util.Map.Entry<K,V>` → `Entry`), trailing parameter name
  tolerated (`int count`). `normalizeLenient` for index-side text.
- `OverloadMatcher` — `matches(Optional<List<String>>, List<ParameterInfo>)`, `matches(List<String>, params)`,
  `matches(MemberReference, MemberDescriptor)` (name, constructor-ness, params; parens never match fields). A
  queried type matches if equal (case-sensitive) to the normalized `erasedType` OR the normalized declared `type`,
  so `T` and `Object` both match a type-variable parameter, `Entry`/`Map.Entry` both match nested types.
- `NamePattern(pattern)` / `NamePattern.parse(text)` — `match(name)` → `Optional<NameMatch>`, `matches(name)`.
  Kinds (`MatchKind`): EXACT, PREFIX (both case-insensitive), CAMEL_HUMPS, SUBSTRING. `NameMatch(kind,
  nameLength)` is Comparable (kind, then shorter first); callers tie-break alphabetically.
  Humps: each pattern char continues the previous match or jumps to a later word start (case-insensitive); first
  char must hit a word start. Word starts: index 0, upper-case letters, first digit of a digit run, char after
  `_`/`$`/`.`/digit. So `HSR`, `hsr`, `HSRequest`, `SR` match `HttpServletRequest`; `UD`/`ULD` `URLDecoder`;
  `XHR` `XMLHttpRequest`; `B64E` `Base64Encoder`; `MV` `MAX_VALUE`. Linear DP, O(pattern × name).
  Note: lower-case `map` hump-matches `HashMap` (M is a word start), ranking it above substring hits.
