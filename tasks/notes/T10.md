## Output formats decided here (outline leaves them open)
- Type header: T07 `ResultHeader`; `[version unresolved]` on library types only (the JDK version is never guessed).
  Sentence headers (`3 matches for x`, `no type named X on this classpath`) get the tag whenever UNRESOLVED.
- class: header, `extends A  implements B, C` (implied Object/Enum/Record/Annotation dropped; line omitted if empty),
  first paragraph, blank, member rows (`[deprecated]` prefix), nested type rows (`class Map.Entry<K, V>`),
  `inherited from X: a, b` (relative name).
- method: per overload a block `signature[  [inherited from X]][  [doc from Y]]`, description, blank, tags;
  `(no documentation)`; blank line between overloads. Member not found: type header, `no member R in T`, `did you
  mean:` + suggestions.
- source: code blocks; notes as `// inherited from X`, `// decompiled`, javadoc-jar doc as `/** */`;
  `// no source: reason` (exit 1 if no overload has source).
- find / member / impls: `ref  label` rows (impls marks `indirect`); find header `N matches for p` (capped:
  `200+ … (best 200 shown)` + hint). package: `pkg  package  (labels)`, doc, `final class Duration  sentence` rows.
- index: `module <dir>  (N artifacts + jdk 25)`, `indexed … , M up to date`, missing sources grouped by artifact,
  ≤ 10 types each then `... and N more`, `failed to index:` lines. Errors: one `error: …` line; usage errors add
  `(see jdoc <cmd> --help)` on the same line.
