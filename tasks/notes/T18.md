## Files
- `it/sample-project/` — one module with commons-lang3 3.20.0 (sources jar), commons-codec 1.19.0 (javadoc jar
  only) and jspecify 1.0.0 (binary only, so it is decompiled). The dependency plugin is pinned to 3.11.0, so the
  priming and jdoc's offline `dependency:list` use the same plugin. `Greeter.java` is the `--from` target.
- `scripts/smoke-test.sh <jar|launcher> <project>` — primes a **private** local repo (`SMOKE_M2_REPO`, default a temp
  dir) online: `go-offline`, `sources` for lang3 only, `resolve -Dclassifier=javadoc` for codec only. It asserts which
  extra jars are present and absent. Then it runs offline with a temp `JDOC_CACHE` and `JDOC_M2_REPO`/`JDOC_MVN`:
  25 calls, covering every command, `--help`, `<cmd> --help`, `--version` (optionally exact), `index`/`--force`
  (missing-sources report), `--page 2`, `--from`, the headers `(jdk`, `(commons-lang3` without a tag,
  `[from javadoc jar]` and `[decompiled, no docs]`, exits 1 (type, method), 2 (`Duration`, and `StringUtils`, which
  turned out to be ambiguous between lang3 and codec) and 3 (unknown command, `--page 0`). It also checks that nothing
  was written into the project. `SMOKE_SHELL=dash` runs the launcher with dash. It never touches ~/.m2 or ~/.cache/jdoc.
- `scripts/assemble.sh <version>` — `JDOC_JAR` (default `target/jdoc.jar`) must report `jdoc <version>`. Bundle:
  `VERSION, install.sh, AGENTS-snippet.md, LICENSE, NOTICE, THIRD-PARTY-NOTICES, bin/jdoc, lib/jdoc.jar,
  skill/SKILL.md`, with explicit modes. The tarball is built with `--sort=name --format=gnu`, mtime =
  `SOURCE_DATE_EPOCH` (default: last commit), owner 0/0, then `gzip -9n`, plus `out/SHA256SUMS`. Two runs gave the
  same sha256. No AOT cache, archive or native library goes in the bundle.
- `scripts/install-test.sh <tarball> [project]` (new, the path users take) — checks `sha256sum -c`, the exact tar
  entry list, owners 0/0, VERSION, exec bits and the licence files at the root. It runs `install.sh` into a prefix
  that contains a space, plus a bindir and a skills dir, and fails on any installer warning. It checks the installed
  jar (`cmp`), the sqlite library, the AOT cache and key, VERSION, `share/doc/jdoc/{LICENSE,NOTICE,THIRD-PARTY-NOTICES}`,
  the skill, and that no placeholders remain. Then `jdoc --version` must be exact and must use the AOT cache (debug
  line), also under `dash` (`INSTALL_TEST_REQUIRE_DASH=1` makes dash mandatory). Next the full smoke test runs through
  the installed launcher (under dash if present). Finally the jar mtime is set to 2000-01-01, and two calls must fall
  back silently to `$JDOC_CACHE/cds/jdoc.jsa` with only the debug line on stderr.
- `dist/skill/SKILL.md`, `dist/AGENTS-snippet.md` — taken from the outline and checked against the real `--help`.
  Added: quoting `'Map#of(Object,Object)'`, camel humps, `package`, exit 3, the `[decompiled, no docs]` meaning, the
  `page 1/N · next:` footer, `index --force` only for stale answers, and `jdoc <command> --help`. Kept minimal (T24
  redesigns the "when to call" part).
- `.github/workflows/build.yml` — actions are pinned to SHAs: checkout v7.0.1, setup-java v6.1.0 (Temurin 25, maven
  cache), upload-artifact v7.0.2, download-artifact v8.0.2, actions/attest v4.2.2. The attest-build-provenance action
  is now only a wrapper around actions/attest. Steps: tools (installs shellcheck/dash only if missing), shellcheck
  on `dist/install.sh dist/bin/jdoc scripts/*.sh`, version, `./mvnw -B -ntp -Drevision=$VERSION verify`, assemble,
  install-test + smoke (dash required), upload `out/`. The release job runs only for `v*` tags. It is the only job with
  write permissions (`contents`, `id-token`, `attestations`, `artifact-metadata`), and it runs
  `gh release create --verify-tag --generate-notes` (`--prerelease` if the tag contains `-`). `concurrency` cancels
  superseded PR runs. `persist-credentials: false`.
- Version: `-Drevision` → manifest `Implementation-Version` → `jdoc --version`. assemble verifies it and writes
  `VERSION`. install-test checks that the installed launcher prints it.
