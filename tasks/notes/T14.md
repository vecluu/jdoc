## cli (`io.github.vecluu.jdoc.cli`), all package-private except `JdocCli`/`CompositionRoot`
- `JdocCli` — unchanged public API (`execute(args)`, `forEnvironment`); parse → help/version on stdout (exit 0) or run.
- `CommandLineParser` — `parse(List<String>) → CliRequest`; `--opt value`, `--opt=value`, flags (`--force`,
  `--force=true|false`), `--` ends options, options before/after the argument, `-h/--help` and `-V/--version` at the top
  level and after a command; errors: missing command, unknown command, unknown option, missing/extra argument, missing
  option value, `--page` not an int or < 1, repeated option, invalid `--from` path.
- `CliRequest` — sealed: `Help(Optional<JdocCommand>)`, `Version`, `Run(JdocCommand, Invocation)`.
- `JdocCommand` — enum of the 8 commands: name, argument label + help line, description, options, `call(app, invocation)`
  (switch, no lambdas/reflection). `OptionDefinition` — record (`FROM`, `PAGE`, `FORCE`). `Invocation` — record
  (argument, from, page, force).
- `HelpText` — hand-written `overview()` / `of(command)`: one line per command with argument syntax, options, option
  forms, exit codes; columns aligned, no wrapping.
- `ManifestVersion` (replaces `ManifestVersionProvider`), `UsageException` (message + `helpHint()`),
  `FailureReporter` (the `error:` lines; holds the only slf4j logger, so slf4j is loaded only on failures).
- Removed: `CommonOptions`, `ManifestVersionProvider`; `JdocCommand` rewritten from a picocli class into the enum. `CommandRunner`, `ResultPrinter`,
  `CommandLineText`, `CompositionRoot` and `Main` unchanged.

## Behaviour
- Error messages keep picocli's wording (`Missing required parameter: '<type>'`, `Unmatched argument at index 2: 'Y'`,
  `Unknown option: '--bogus'`, `Missing required parameter for option '--from' (<path>)`, `Invalid value for option
  '--page': 'two' is not an int`) plus ` (see jdoc <cmd> --help)`; exit 3. New: `is not a boolean`, repeated option.
- Fixed: `jdoc` without arguments printed `(see jdoc --help)` twice; now once.
- Help text shape changed (hand-written, no picocli `[-hV]`/wrapping); `Usage: jdoc`, `Usage: jdoc <cmd>`, the exit-code
  line and every command/option are still present. `-V` is no longer listed in each command's help (still accepted).
