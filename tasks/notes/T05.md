# T05 notes — bytecode (ASM) and javadoc-jar HTML

Status: done. `./mvnw -B -q -Djdoc.buildDir=target/T05 verify` passes (whole tree, at time of writing).

## bytecode (public API)
- `BinaryJarScanner` (interface) — `scan(jar, Consumer<ScannedClass>) → JarScanSummary` (streams one class at a
  time), `readClass(jar, TypeName) → Optional<ScannedClass>`, default `scanAll(jar)`. Throws `JarReadException`.
- `ZipBinaryJarScanner` — `ZipFile` implementation. Skips `META-INF/**` (so `META-INF/versions/**` never wins),
  `module-info`, directories/non-class entries; `package-info.class` only recorded; unreadable classes logged + counted.
- `JarScanSummary(typeCount, skippedEntries, packageInfoPackages)`.
- `ClassFileReader` — `read(byte[]) → Optional<ScannedClass>` (ASM, `SKIP_CODE|SKIP_FRAMES`); empty for
  module/package-info, synthetic, anonymous, local classes and anything nested in them; `IllegalArgumentException`
  for invalid bytes.
- `ScannedClass(TypeDescriptor type, List<MemberDescriptor> members)`.
- Package-private: `SignatureParser` + `JvmType` (descriptor/generic-signature AST), `TypeRenderer`, `ClassCollector`
  (ASM visitor → `RawClass`), `TypeDescriptorFactory`, `MemberDescriptorFactory`, `AccessFlags`.

## javadoc, HTML-page side (public API)
- `JavadocPageSource` (interface: `page(entryPath)`, `hasPage`) and `JavadocJar` (`open(path)`, AutoCloseable, keeps the
  zip open; honours `<meta charset>`, default UTF-8).
- `JavadocJarReader(pages, parser)` — `typePage(TypeName)`, `hasTypePage`, `packageDoc(pkg)`; static
  `typePagePath` (`a/b/Outer.Inner.html`), `packagePagePath` (`a/b/package-summary.html`).
- `JavadocPageParser` — `parseTypePage(html, type) → JavadocTypePage`, `parsePackagePage(html, pkg) → RenderedDoc`.
- `JavadocTypePage(type, typeDoc, members)` — `memberDoc(MemberDescriptor)`: exact anchor match, else unique
  name+arity match, else empty. `JavadocMemberDoc(anchors, doc)`.
- `JavadocAnchor(name, Optional<List<String>> parameterTypes)` — `parse(id)` (modern `of(java.lang.Object)`,
  `max(T,T)`, `<init>(..)`, `%3Cinit%3E`; legacy `of-java.lang.Object-`, `:A`; fields `NAME`),
  `generate(name, kind, qualifiedTypes, Layout)`, `generate(MemberDescriptor, Layout)`, `matches`, `matchesLoosely`.
- Package-private: `JavadocSectionRenderer` (section → `RenderedDoc`), `JavadocLinkRewriter`.

## Decisions
- `ScannedClass.type()` has `docSource=DECOMPILED`, `entryPath=a/b/Outer$Inner.class`, empty first sentence: the
  indexer (T08) overrides via `toBuilder()` once it picked the doc source. Package-private/private *types* are
  returned (with their visibility; filter with `isApi()`); *members* are public/protected only.
- Signatures were aligned with T04's actual output and verified member-by-member (`SampleLibraryBytecodeIT`):
  nested types as `Outer.Inner` (relative name, also inside the outer type: `Shapes.Registry.Entry`), type args
  joined by `", "`, implicit modifiers shown (`abstract` on interface/annotation methods, `static final` on interface
  fields), supertypes include the implicit `Object`/`Enum`/`Record` superclass and `Annotation` for annotation types,
  none for interfaces. Type modifiers: visibility, abstract (classes), static (nested), final (classes), sealed.
- Inner-class constructors drop the outer-instance parameter; `MethodParameters` names are aligned when the attribute
  also covers mandated/synthetic params; otherwise `argN`.
- Javadoc HTML: links with a member fragment whose text is javadoc's generated label are rewritten to `Foo#bar(int)`
  (same page: `#bar(int)`, exactly what T04 renders for `{@link #bar(int)}`); explicit labels unchanged.
- Block tag order is the conventional comment order (`@apiNote/@implSpec/@implNote`, `@param` (type params first),
  `@return`, `@throws`, `@see`, `@since`, `@deprecated`) since HTML loses comment order. Dropped: "Specified by",
  "Overrides", "Default", generated "See Also: Constant Field Values", empty deprecation blocks (javadoc adds them to
  members of deprecated types), and an `@since` that javadoc 25 copies from the enclosing type onto nested types
  (`JavadocJarReader` removes it when it equals the outer page's `@since`).
- Empty member sections render as `RenderedDoc.missing()` (inheritsDoc=true).
- `bytecode` and `javadoc` use `error.JarReadException` (architecture table lists only `model` for them; the guide
  requires wrapping I/O errors into the `error` hierarchy).

## Known differences to source parsing (by nature of the input)
- Records: bytecode lists `toString()/hashCode()/equals(Object)` (javac generates them, javadoc documents them).
- javadoc already resolves `{@inheritDoc}` and copies docs of undocumented overrides; implicit members (record
  accessors, `valueOf`, canonical ctor) carry javadoc's generated text, not T04's synthesized text.
- Fully qualified `{@link java.util.List#add}` renders as `List#add(Object)` from HTML.
- Generic outer chains (`Outer<T>.Inner`) are rendered as a chain; T04 does the same when written so.
